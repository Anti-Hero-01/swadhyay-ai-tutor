# Swadhyay — An AI Tutor

This repository contains the frontend for Swadhyay, an AI-powered learning platform for microcontrollers and embedded systems. It uses React, TypeScript, Tailwind CSS, and shadcn-ui components.

Local development

```sh
git clone <YOUR_GIT_URL>
cd <YOUR_PROJECT_NAME>
npm install
npm run dev
```

Tech stack

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

To deploy, build with `npm run build` and serve the `dist` folder using your preferred hosting provider.
